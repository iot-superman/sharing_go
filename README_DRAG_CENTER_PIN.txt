共乘 Go - iPhone 拖曳地圖中央圖釘選點版

這版改成更接近 Google Maps / Uber 的選點方式：

1. 地圖中央固定一個 📍 圖釘。
2. 手指拖曳的是「地圖」，圖釘固定在中央。
3. 放開手指後，自動把中央圖釘所在座標設為選定位置。
4. 放手後才做一次地址反查，不會在拖曳過程一直呼叫 Nominatim。
5. 點一下地圖也可以，系統會把點擊位置移到中央並自動選定。
6. 「目前位置」會把 GPS 移到中央圖釘並自動選定。
7. iPhone / LINE WebView 全螢幕精確選點修正仍保留。
8. http://192.168.x.x 時，即使 GPS 被限制，手動拖曳地圖仍可使用。

使用方式：
建立共乘
→ 精確選
→ 用手指拖曳地圖
→ 讓中央 📍 對準要的位置
→ 放手
→ 自動反查地址
→ 使用這個位置
